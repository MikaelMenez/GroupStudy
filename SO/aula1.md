# Divisão 
- Hardware
- Software

## Hardware
- unidade básica é o transistor
- utiliza transistores para criar portas lógicas
- a partir das portas lógicas se cria circuitos lógicos
- circuitos lógicos são usados para criar memória, ulas, etc
- ao juntar tudo isso podemos criar uma cpu

## Software
- o mais alto nível são as linguagens de alto nível
- a linguagem vai ser compilada para assembly específica da cpu
- depois o código em assembly vai passar pelo assembler e virar um binário
- o binário é cheio de instruções e dados
- **o sistema operacional vai ser o software responsável por lidar com a cpu e a memória**
