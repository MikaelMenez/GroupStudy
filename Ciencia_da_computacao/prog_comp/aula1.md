# Map 
- é uma estrutura baseada em pares {key,value }
- inserção, remoção e consulta em O(log n)
- implementado com árvore rubro-negra

# Set
- conjunto de elementos únicos 
- inserção, remoção e consulta em O(log n)
- implementado com árvore rubro-negra
- multiset permite múltiplas ocorrências

# Fila de prioridade
- estrutura que permite acesso ao maior (ou menor) elemento com prioridade
- inserção e remoção do topo em O(log n)
- implementado com heap binário (por padrão)
- não há suporte direto para verificação de existência

# Deque
- permite inserção, remoção no início e no fim com O(1)
- é implementado com 2 ponteiros, um pro início e um pro final
