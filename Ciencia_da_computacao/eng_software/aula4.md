# Processos de software
Conjunto de atividades relacionadas que levam à produção de um sistema de software .
têm diversos tipos de Processos de software,a escolha depende do tipo de software, requisitos do cliente, das experiências da equipe, da cultura organizacional. **Não existe um processo universal e aplicável a qualquer situação**

## atividades
- especificação
  - define as funcionalidades do software a ser produzido e suas restrições
- Desenvolvimento
  - Projeta a organização do sistema e implementa o software especificado 
- Validação 
  - avalia o software para garantir que atende às necessidades do cliente
- Evolução
  - modifica o software para atender mudanças nas necessidades do cliente

## Descrição 
a Descrição do processo de software envolve identificar as atividades constituintes e a ordem de realização
- é em essência o relato de tudo que as pessoas fazem para desenvolver um sistema de software
- Deve-se descrever quem está envolvido nas atividades e o que é produzido em cada atividade 
- É importante descrever as condições que influenciam na sequência de atividades
